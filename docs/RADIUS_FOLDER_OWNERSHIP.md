# Folder ownership and safety

`radius_inbound_folder`, `radius_outbound_folder`, `partner_inbound_folder`, and `partner_outbound_folder` are separate capability fields. `working_folder`, `archive_folder`, and `quarantine_folder` are also distinct. The current observer reads only the Radius inbound folder for an inbound VAN capability and the Radius outbound folder for an outbound VAN capability. It skips symlink files, samples size and modification time twice, hashes stable bytes, and does not rename, move, delete, or write a Radius/VAN file.

Enabling observation requires an operator-verified Radius folder contract, Radius message active flag, and an absolute folder inside `EDI_CENTRAL_ALLOWED_ROOTS`. The worker checks the allowed root again at scan time. LIVE additionally requires the explicit read-only authorization flag `EDI_CENTRAL_LIVE_OBSERVATION=1` on enable and scan. The user's authorized Niagara LIVE 856 folder is documented in [NIA01_856_MONITOR.md](NIA01_856_MONITOR.md). **TO VERIFY:** provider ownership details, cleanup timing, atomic publication behavior, and whether an approved outbound pickup receipt exists. File disappearance alone must never be recorded as successful VAN pickup.
